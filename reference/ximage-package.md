# ximage: Draw Images of Raster Data and Related Adornments

Draw images easily, set up a plot with an image, specify where that
image should be placed. Image plot by default reflects the index of the
image data itself, or can be specified in simple extent terms
'xmin,xmax,ymin,ymax'. Numeric matrices, integer arrays, byte arrays,
character arrays, and native rasters are supported. Flat vectors are
supported in a limited sense with a heuristic to guess at the likely
dimensionality and some helpers. A combination of image() and
rasterImage() from the 'graphics' package with their good features in
one place.
